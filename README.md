
# Azure Lab

Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do 1º Lab Microsoft Azure


## Aprendizados

- Apresentação sobre serviços em nuvem. 
- Criar uma conta gratuita no site [Microsoft -Azure](https://azure.microsoft.com/pt-br/pricing/purchase-options/azure-account/)

- Uma visão geral sobre os beneficios da computação em nuvem, como definir modelos de nuvem: público, privado e híbrido. Identificação dos casos de uso apropriados para cada modelo, visando oferecer o melhor custo para clientes e empresas que desejam migrar os seus serviços e recursos para nuvem.
- Um comparativo entre despesas de captial (Capex) e despesas operacionais (Opex), para entender onde cada despesa pode ser empregada de maneira correta.
- Modelo baseado em consumo, que permite a previsão de custos com informações de preços para recursos e serviços individuais, sendo a cobrança realizada apenas com base no consumo real.
